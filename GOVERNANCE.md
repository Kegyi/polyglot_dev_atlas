Governance (Phase 7 starter)
=============================

Scope
-----
Defines roles, responsibilities, and lightweight processes to maintain the Polyglot Dev Atlas project.

Roles
-----
- Maintainers: responsible for reviewing PRs, merging, and enforcing CI policy.
- Release owner: prepares release notes, tags releases, and ensures the release checklist is followed.
- Contributors: open PRs, follow `CONTRIBUTING.md`, and include tests and validation runs.

Pull request process
--------------------
- Small focused PRs preferred.
- Include test runs and, for performance-sensitive changes, profiler outputs attached as artifacts.
- Maintainers should request changes or approve. At least one approval required before merge.

Release process
---------------
- Follow `RELEASE_CHECKLIST.md` before tagging.
- Release owner drafts release notes and creates a GitHub release.

Conflict resolution
-------------------
- If maintainers disagree, escalate to the project lead for a final decision.
